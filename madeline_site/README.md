# For Madeline

A romantic, responsive static website built for GitHub Pages.

## Preview locally
Open `index.html` in a browser. Internet access is used for Google Fonts and the embedded YouTube song.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `for-madeline`).
2. Upload `index.html` and the `assets/` folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then **Save**.
5. Wait for GitHub Pages to publish the site. Its URL will appear in Settings → Pages.

## Personalize
- The bouquet-and-kitten picture is `assets/bouquet-kitten.png`.
- Edit the wording in `index.html` to make it sound more like you.
- The music is embedded from YouTube. Playback can depend on regional availability, browser settings, and YouTube embed permissions. A YouTube search link is included as a fallback.

## Note
This is a static page; it doesn't collect or send visitor information.
