# For Madeline

A romantic, responsive static website built for GitHub Pages.

## Preview locally
Open `index.html` in a browser. The page uses Google Fonts and an embedded Spotify player, so those features need an internet connection.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `for-madeline`).
2. Upload `index.html`, `README.md`, and the complete `assets/` folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then **Save**.
5. The published URL will appear in Settings → Pages after deployment completes.

## Personalize
- The bouquet-and-kitten picture is `assets/bouquet-kitten.png`.
- Edit the wording in `index.html` to make it sound more like you.
- The music player embeds Bruno Mars' **Just the Way You Are** from Spotify. Playback may depend on Spotify availability, region, browser settings, or whether the listener is signed in. The **Open in Spotify** link is provided as a fallback.

## Note
This is a static page; it doesn't collect or send visitor information.
